第一课

从 DMA 到 RDMA

理解 DMA 的基本概念，以及 RDMA 如何将 DMA 扩展到远端。对比传统 socket 与 RDMA 的关键差异，概览四种 RDMA 传输实现。

DMA零拷贝传输
第二课

设备发现与环境建立

学习如何发现 RDMA 设备、查询端口属性、理解 GID 概念。用 rping 完成第一个 RDMA 通信。

设备GIDrping
第三课

Verbs 核心对象模型

深入理解 Context、PD、MR、CQ、QP 五个核心 objects 的作用、创建顺序和销毁顺序。WR 与 WC 的配对关系。

Verbs对象生命周期
第四课

数据路径深入

追踪一个字节从发送缓冲区到接收缓冲区的完整旅程。通过 SEND、RECV、RDMA WRITE 三种操作理解控制面与数据面的分离。

数据面SENDWRITE
第五课

RDMA 连接模型

两种连接方法：手工 TCP 交换元数据 + raw verbs vs RDMA CM 事件驱动模型。QP 状态机详解。

连接CM状态机
第六课

从 raw verbs 走向生产

探讨 libfabric、UCX、MPI、NCCL 在生产中的定位。了解为什么生产代码很少直接使用 raw verbs，以及本课程的六课知识如何复用。
