#04 QOM 属性系统

属性系统是 QOM 的 "魔法"——它让你能在运行时自省和修改对象， 是 QMP monitor 中 qom-list/qom-get/qom-set 的底层机制， 也是 -device pci-device,property=value 命令行参数的工作方式。

4.1 ObjectProperty 结构

/* include/qom/object.h:89 */
struct ObjectProperty
{
    char *name;                      /* 属性名称 */
    char *type;                      /* 属性类型描述 (QAPI type) */
    char *description;               /* 人类可读的描述 */
    ObjectPropertyAccessor *get;     /* getter: (obj, visitor, name, opaque, errp) */
    ObjectPropertyAccessor *set;     /* setter: 同上 */
    ObjectPropertyResolve *resolve;  /* 路径解析 (用于 child<> 属性) */
    ObjectPropertyRelease *release;  /* 属性被删除时的回调 */
    ObjectPropertyInit *init;        /* 属性创建时的回调 */
    void *opaque;                    /* 传递给 get/set 的不透明数据 */
    QObject *defval;                 /* 默认值 */
};

属性的核心是 Visitor 模式——getter 和 setter 不直接读写值， 而是通过 Visitor 接口间接操作。

4.2 Visitor 模式

QOM 属性不直接返回 int 或 char*，而是使用 Visitor： 

/* include/qom/object.h:43 */
typedef void (ObjectPropertyAccessor)(Object *obj,
                                      Visitor *v,
                                      const char *name,
                                      void *opaque,
                                      Error **errp);
┌──────────────┐ qom-get "mac" ──→ │ StringOutput │ ← visitor 负责"收集"值 │ Visitor │ └──────┬───────┘ │ visit_type_str(v, "52:54:00:12:34:56") ▼ ┌──────────────┐ │ nic_get_mac │ ← getter 负责"提供"值 └──────┬───────┘ │ NICState.mac[] ┌──────┴───────┐ │ NICState │ └──────────────┘ ┌──────────────┐ qom-set "mac" ──→ │ StringInput │ ← visitor 负责"携带"新值 │ Visitor │ └──────┬───────┘ │ visit_type_str(v, "52:54:00:ab:cd:ef") ▼ ┌──────────────┐ │ nic_set_mac │ ← setter 负责"应用"值 └──────┬───────┘ │ NICState.mac[] = ... ┌──────┴───────┐ │ NICState │ └──────────────┘

Visitor 是读/写通道的抽象。同一套 getter/setter 逻辑，换上不同 Visitor 就能支持不同序列化格式（JSON、QMP、字符串）。这是一种经典的 双调派 (double dispatch) 模式： visitor.visit_X(obj.field) → visitor 知道自己要做什么（序列化/反序列化）， obj 知道自己有哪些字段。

4.3 object_property_add —— 添加属性

/* include/qom/object.h:1107 */
ObjectProperty *object_property_add(Object *obj, const char *name,
                                    const char *type,
                                    ObjectPropertyAccessor *get,
                                    ObjectPropertyAccessor *set,
                                    ObjectPropertyRelease *release,
                                    void *opaque);

添加属性的典型用法（在 instance_init 中）：

static void my_device_init(Object *obj)
{
    MyDevice *dev = MY_DEVICE(obj);

    /* 方式 1: 手动添加属性，自定义 getter/setter */
    object_property_add(obj, "mac", "str",
                        my_device_get_mac,
                        my_device_set_mac, NULL, dev);

    /* 方式 2: 添加子对象 (child<> 属性) */
    object_property_add_child(obj, "mmio[0]", OBJECT(&dev->mmio));
}

QOM 还有一系列属性便捷包装：

/* 标量类型属性 */
object_property_add_uint8_ptr(obj, "revision", &dev->revision);
object_property_add_uint32_ptr(obj, "freq_hz", &dev->freq_hz);
object_property_add_bool(obj, "enabled",
                         my_get_enabled, my_set_enabled);

/* Link 属性 —— 指向另一个 QOM 对象的链接 */
object_property_add_link(obj, "dma", TYPE_DMA_ENGINE,
                         (Object **)&dev->dma,
                         NULL, OBJ_PROP_LINK_STRONG);

4.4 Static Properties（静态属性）

手动 object_property_add 对每个对象都要执行。 设备更常用的是 静态属性表 —— 在 class_init 中一次性注册， 每个实例自动拥有： 

/* 在 class_init 中: */
static Property my_device_properties[] = {
    DEFINE_PROP_UINT32("freq",    MyDevice, freq_hz, 1000000),
    DEFINE_PROP_STRING("serial",   MyDevice, serial),
    DEFINE_PROP_BOOL("enabled",  MyDevice, enabled, true),
    DEFINE_PROP_MACADDR("mac",   MyDevice, mac),
    DEFINE_PROP_END_OF_LIST(),
};

static void my_device_class_init(ObjectClass *oc, void *data)
{
    DeviceClass *dc = DEVICE_CLASS(oc);
    device_class_set_props(dc, my_device_properties);
}

DEFINE_PROP_UINT32("freq", MyDevice, freq_hz, 1000000) 的语义： 创建一个名为 "freq" 的属性，getter/setter 自动读写 MyDevice 结构体的 freq_hz 字段，默认值 1000000。

Static vs Dynamic 属性：
  • Static (Property struct): class_init 中注册，所有实例共享元信息，通过 property offset 直接读写 struct 字段，性能高
  • Dynamic (object_property_add): instance_init 中注册，getter/setter 是自定义函数，灵活性高

4.5 属性子类型

类型API用途
child<>object_property_add_childcomposition tree 父子链接
link<>object_property_add_link跨树的对象引用 (软/硬链接)
boolobject_property_add_bool布尔开关
strobject_property_add_str字符串
uint32object_property_add_uint32_ptr32 位无符号整数
child 属性是 composition tree 的边 —— 当你调用 object_property_add_child(parent, "nic", nic_obj) 时， 实际上做了两件事：(1) 在 parent 上创建名为 "nic" 的 child<> 属性； (2) 设置 nic_obj->parent = parent，把 nic 挂到 composition tree 上。 qom-tree 显示的就是这棵 composition tree。

4.6 QMP Monitor 交互

属性系统的直接体现就是 QMP monitor 中的 QOM 命令：

(QEMU) info qom-tree
/machine (virt-machine)
  /peripheral (container)
  /unattached (container)
    /device[0] (e1000)
      /mac = "52:54:00:12:34:56"  ← 这就是 object_property_add 的效果
      /freq = 1000000
      /enabled = true

(QEMU) qom-list /machine/peripheral
device[0] (child<e1000>)

(QEMU) qom-get /machine/peripheral/device[0] mac
"52:54:00:12:34:56"

(QEMU) qom-set /machine/peripheral/device[0] mac "52:54:00:ab:cd:ef"
(QEMU) qom-get /machine/peripheral/device[0] mac
"52:54:00:ab:cd:ef"

4.7 命令行参数与属性

-device e1000,mac=52:54:00:12:34:56,freq=1000000 的工作链路：

qemu-system-x86_64 -device e1000,mac=52:54:00:12:34:56 │ ├─ [1] QemuOpts 解析: { "driver" → "e1000", "mac" → "52:54:..." } │ ├─ [2] object_new("e1000") ← 创建实例, instance_init │ ├─ [3] object_set_properties_from_qdict(obj, opts) │ └─ for each key-value: │ object_property_set(obj, "mac", "52:54:...", &err) │ └─ prop->set(obj, string_input_visitor, "mac", prop->opaque, &err) │ └─ [4] qdev_device_add_from_qdict(opts, &err) └─ device_set_realized(dev, true, &err) └─ DeviceClass::realize(dev, &err)

类似的，-object memory-backend-ram,id=mem0,size=1G 也是同一套链路：

/* backends/hostmem.c 中定义: */
static Property host_memory_backend_properties[] = {
    DEFINE_PROP_SIZE("size", HostMemoryBackend, size, 0),
    DEFINE_PROP_BOOL("share", HostMemoryBackend, share, false),
    ...
};

/* 用户通过 -object memory-backend-ram,id=mem0,size=1G,share=on
   设置 HostMemoryBackend.size 和 HostMemoryBackend.share 字段 */
