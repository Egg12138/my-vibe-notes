PCIe & CXL 教学课件

通过 9 个实验，从虚拟 PCI 视图到 CXL 内存语义，逐层理解现代 I/O 协议栈

QEMU q35 Linux Kernel BusyBox initramfs sysfs 配置空间 CXL 2.0

学习路线

先建立模型，再解释观察

每个实验都从 Linux 能观察到的对象出发，但课程不把命令输出当作结论。先区分 guest 看见的虚拟 PCI 视图与物理硬件；再用配置空间、BDF 和桥解释设备如何被发现；随后用 BAR、驱动和中断解释设备如何被使用；最后把同一套 PCIe 基础带到 CXL 的内存寻址路径。

  1. 设备如何被看见：实验 01–04 建立虚拟化边界、枚举、BDF、桥和配置空间的模型。
  2. 设备如何被使用：实验 05–07 连接 MMIO 地址、驱动生命周期和 MSI/MSI-X 中断。
  3. 内存如何变得可访问：实验 09–10 说明 CXL 如何复用 PCIe 发现设备，并额外完成地址解码与 region 编程。
阅读方法：先读每讲的“原理”，预测 Linux 会暴露什么对象，再运行已有实验。若输出与模型不一致，优先检查这是平台或 QEMU 的虚拟化行为，还是概念本身。
