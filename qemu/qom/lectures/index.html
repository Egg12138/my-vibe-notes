QEMU QOM (QEMU Object Model) 深度教学

QOM 是 QEMU 的类型系统 —— 它是 QEMU 中所有设备、总线、Machine、MemoryBackend 的基石。 这套讲座从 C 语言 OOP 的困境出发，逐层深入到 QOM 的类型注册、生命周期、属性系统、继承与接口， 最终通过一个完整的实战案例，让你能够定义自己的 QOM 类型。

所有代码示例均来自 QEMU include/qom/object.h, qom/object.c, include/hw/qdev-core.h, hw/core/qdev.c 等实际源文件。
